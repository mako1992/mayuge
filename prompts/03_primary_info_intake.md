# STEP 3. 写真・一次情報の整理（ChatGPT）

写真・音声メモ（文字起こし）・メモ書きをそのまま渡す。

---

```
Selected topic: [選んだ案をそのまま貼る]

I'm attaching my raw first-hand materials: photos, voice-memo transcripts (in Japanese), and notes.

Please:
1. Describe what each photo shows that is relevant to the topic
   (product, price tag, shelf placement, POP signage, date/store type if visible).
2. Extract facts from my notes/voice memos and translate them into English.
3. List my personal opinions/experiences separately from facts.
4. Flag anything that needs verification before publishing (prices, numbers, company names).
5. Suggest which 2–4 photos to use, where in the article, and an English caption for each.
6. Tell me what is missing to make this issue strong (max 3 items).

Output as a structured list. Do NOT write the article yet.
```

自分のやること：足りないと言われた素材があれば追加で渡す。
