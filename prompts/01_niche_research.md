# 01. ニッチ選定（初回のみ）

参考：X の投稿で紹介されていたプロンプトをベースにしています。
出てきた候補の中から、**日本での実績・一次情報とセットにできるもの**を選ぶのがポイント。

---

```
あなたはSubstack有料購読ニュースレターの専門アナリストです。

以下の条件で「英語圏で月$500以上稼げる」ニッチテーマを10個抽出してください。

1. 有料購読者を集めやすいテーマ(月額$5〜10)
2. 日本人発信者がほぼいないブルーオーシャン
3. 週1本のニュースレターで継続配信できる分量
4. B2Bまたは特定属性向けの尖ったニッチ
5. 英語圏で継続的な需要がある

各テーマについて、以下を表形式で:
・テーマ名(英語で)
・想定ターゲット(職業/年収/悩み)
・想定月額($)
・想定購読者数の伸び方(月あたり)
・配信するコンテンツ例5つ
・競合発信者の状況(ライバルの数)

同じジャンルに偏らないよう、
最低5カテゴリー(ビジネス/テック/ライフスタイル/クリエイティブ/投資)に分けて出してください。
```
