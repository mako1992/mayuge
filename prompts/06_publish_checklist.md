# STEP 6–7. 入稿・公開チェックリスト

Substack は公式投稿 API がないため、エディタへのコピペで入稿する。
（Markdown をそのまま貼るとレイアウトが崩れることがあるので、見出し・太字はプレビューで確認）

## STEP 6：下書き入稿
- [ ] 01 のタイトル案から 1 つ選び、Title / Subtitle に入力
- [ ] 02 Free section を貼り付け
- [ ] `<!-- PAYWALL -->` の位置に Substack の「Paywall」ブロックを挿入
- [ ] 03 Paid section を貼り付け
- [ ] 04 の問いと CTA（Subscribe ボタン / Share ボタン）を配置
- [ ] `[PHOTO n]` の位置に画像を挿入し、キャプションを入れる
- [ ] `[CHECK: ...]` が 1 つも残っていない
- [ ] Settings：SEO description（05 から）、サムネイル画像、タグ
- [ ] Audience：Everyone（無料部分を全員に）/ 有料のみ にするか確認
- [ ] プレビュー（Web とメール両方）を確認 ←（自分）

## STEP 7：公開
- [ ] 価格・数字・社名・日付を最終確認
- [ ] 公開 or 予約投稿（読者のタイムゾーンに合わせる：例 米東海岸の朝）←（最終承認）
- [ ] 05 の Notes 投稿を公開後に投稿（当日 1 本、翌日以降に残り）
- [ ] `issues/<号フォルダ>/issue.md` の結果欄を記入

## 公開 1 週間後に記録すること
- 開封率 / クリック率 / 新規フリー購読 / 有料転換 / 返信数
- よかった点・次回変える点 → 再利用できるものは `rules/style_rules.md` へ
